A Laravel Wrapper for Steady.page API

## Installation

You can install the package via Composer:

```bash
composer require bob-kosse/laravel-steady-page-api
```

You may publish all of the package's resources at once:

```bash
php artisan vendor:publish --tag="laravel-steady-page-api"
```

Or, you may publish each resource individually:

### Publishing the Configuration File

```bash
php artisan vendor:publish --tag="laravel-steady-page-api-config"
```
